# SimHash datasets

Набор предназначен для исследования 64-битного SimHash на немецких текстах.

## Файлы

- `base_documents.csv` — 300 исходных документов.
- `simhash_pairs_train.csv` — 3000 размеченных пар.
- `simhash_pairs_validation.csv` — 1000 размеченных пар.
- `simhash_pairs_test.csv` — 1000 размеченных пар.
- `simhash_pairs_preview.csv` — 40 строк для быстрой ручной проверки.
- `dataset_statistics.json` — статистика набора.

## Разметка

`label = 1` означает, что второй текст получен из первого небольшой модификацией и считается почти дубликатом.

`label = 0` означает пару разных исходных документов.

Для отрицательных примеров используются два типа:

- `hard_negative_same_topic` — разные тексты одной темы;
- `easy_negative_different_topic` — тексты разных тем.

## Изменения положительных примеров

- `case_punctuation` — изменение регистра и пунктуации;
- `delete_words` — удаление небольшой части слов;
- `replace_words` — замена нескольких слов близкими вариантами;
- `reorder_sentences` — перестановка соседних предложений;
- `add_sentence` — добавление одного тематически связанного предложения;
- `combined_light` — несколько слабых изменений одновременно.

## Колонки CSV

- `pair_id` — идентификатор пары;
- `split` — train, validation или test;
- `label` — 1 или 0;
- `pair_type` — тип пары;
- `mutation` — способ изменения;
- `first_document_id`, `second_document_id` — идентификаторы документов;
- `first_topic`, `second_topic` — темы;
- `first_text`, `second_text` — сравниваемые тексты.

## Рекомендуемый порядок работы

1. На `train` исследовать размеры шинглов и диапазон порогов.
2. На `validation` выбрать размер шингла и порог расстояния Хэмминга.
3. На `test` один раз посчитать итоговые TP, FP, TN, FN, precision, recall и F1.

Документы разных частей не пересекаются, поэтому итоговая проверка не использует тексты,
по которым подбирались параметры.

## Ограничение

Это синтетический размеченный набор, подготовленный для разработки и воспроизводимого
эксперимента. Для окончательного отчёта его можно дополнить большим реальным корпусом,
а разметку почти дубликатов создавать теми же контролируемыми преобразованиями.
